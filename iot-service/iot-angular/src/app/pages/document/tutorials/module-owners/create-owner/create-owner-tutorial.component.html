Apa itu Create Owner?

Create Owner adalah halaman form untuk onboarding owner baru ke dalam IoT platform. Owner adalah client company/organization yang memiliki project, nodes, dan sensors.

Owner = Top-Level Entity (Multi-Tenant)

Dalam multi-tenant IoT platform, hierarchy adalah:

  • Owner (Company: PT ADHI WATER) → memiliki beberapa Projects
  • Project (Factory A - Water Treatment) → contains multiple Nodes
  • Node (ESP-WTP-01) → has multiple Sensors
  • Sensor (Power Meter) → generates Telemetry data
Kenapa Penting?
  • Multi-Tenant Isolation: Setiap owner hanya bisa akses data mereka sendiri
  • Client Onboarding: First step untuk deploy IoT solution untuk new client
  • Contact Management: Store company info & contact person
  • SLA Tracking: Assign service level agreement (Platinum/Gold/Silver/Bronze)
  • Data Forwarding Setup: Configure webhook atau database untuk export telemetry data
  • Billing Reference: Owner data used untuk invoicing & usage reports

Cara Akses Create Owner Form

Ada beberapa cara untuk mengakses Create Owner Form:

Via Owner List Page (Primary)
  1. Navigate to IoT → Owners menu
  2. Klik tombol "Add New Owner" (plus icon) di pojok kanan atas
  3. Create Owner form akan terbuka
Via Dashboard Quick Action
  1. Dari Main Dashboard, klik quick action "New Owner"
  2. Direct link ke create owner form
Via Direct URL

Akses langsung via browser:

https://your-domain.com/iot/owners/add

Form Fields & Interface

Form Create Owner terdiri dari beberapa sections:

Basic Information (Required)
  • Owner Name Required
    • Company/organization legal name
    • Example: "PT ADHI WATER", "Smart City Jakarta", "PERTAMINA Oil & Gas"
    • Must be unique in the system
  • Industry (Dropdown)
    • Options: Water Treatment, Manufacturing, Oil & Gas, Plantation, Agriculture, Mining, Other
    • Used untuk categorization & analytics
Contact Information
  • Contact Person Required
    • Primary contact name (PIC - Person in Charge)
    • Example: "Budi Santoso", "Jane Doe"
  • Contact Email
    • Email for notifications & reports
    • Must be valid email format
    • Example: "budi.santoso@adhiwater.com"
  • Contact Phone
    • Phone number with country code
    • Example: "+62 812-3456-7890"
Service Level & Additional Details
  • SLA Level (Dropdown)
    • Options: Platinum, Gold, Silver, Bronze
    • Determines support response time & features access
    • Platinum = highest priority, Bronze = basic support
  • Address
    • Company address (textarea)
    • Used untuk documentation & reporting
  • Notes
    • Internal notes/remarks (textarea)
    • Not visible to owner users
Data Forwarding Settings
  • Enable Webhook (Toggle Switch)
    • ON = Real-time telemetry push ke external endpoint
    • OFF = No webhook forwarding
  • Webhook URL
    • External endpoint untuk receive telemetry data
    • Example: "https://api.example.com/webhook"
    • Required jika webhook enabled
    • Disabled (grayed out) jika webhook toggle OFF
  • Enable Database Storage (Toggle Switch)
    • ON = Store telemetry data ke external database (MySQL/PostgreSQL)
    • OFF = No database forwarding
  • Batch Size
    • Number of records per batch (1-1000)
    • Default: 100
    • Higher batch = better performance, lower latency = smaller batch
Preview Panels (Bottom)
  • Owner Summary (Left Panel)
    • Live preview of entered data
    • Shows: Name, Industry, Contact, Email, Phone
    • Updates instantly as you type
  • Payload Preview (Right Panel)
    • JSON representation of API payload
    • Useful untuk developers/debugging
    • Shows exact data yang akan dikirim ke backend

Cara Menggunakan

Create New Owner (Full Process)
  1. Navigate to Create Form:
    • Go to IoT → Owners
    • Klik "Add New Owner" button
  2. Fill Basic Information:
    • Owner Name: Type company name (e.g., "PT ADHI WATER")
    • Industry: Select from dropdown (e.g., "Water Treatment")
  3. Fill Contact Information:
    • Contact Person: Enter PIC name (e.g., "Budi Santoso")
    • Contact Email: Enter email (e.g., "budi@adhiwater.com")
    • Contact Phone: Enter phone with country code (e.g., "+62 812-3456-7890")
  4. Select SLA Level:
    • Choose from dropdown: Platinum/Gold/Silver/Bronze
    • Default: Gold
  5. Add Address & Notes (Optional):
    • Address: Type company address
    • Notes: Internal remarks/special instructions
  6. Configure Data Forwarding (Optional):
    • If need webhook:
      • Toggle "Enable Webhook" ON
      • Enter Webhook URL (e.g., "https://api.client.com/iot-data")
    • If need database storage:
      • Toggle "Enable Database Storage" ON
      • Set Batch Size (default 100 is good untuk most cases)
  7. Review Preview:
    • Check Owner Summary panel - verify info correct
    • Check Payload Preview panel - ensure no missing required fields
  8. Submit Form:
    • Klik "Save Owner" button
    • Wait for success notification
    • System akan redirect ke Owner List page
    • New owner akan highlighted (background color) di list

Result: New owner created & ready untuk project deployment

Field Validation Behavior

Form memiliki built-in validation:

  • Required Fields:
    • Owner Name - must not be empty
    • Contact Person - must not be empty
    • Industry - auto-selected (default: first option)
  • Email Validation:
    • If filled, must be valid email format
    • Invalid format shows red border + error message "Invalid email format"
  • Number Validation:
    • Batch Size must be 1-1000
    • Browser prevents typing non-numeric characters
  • Conditional Required:
    • If webhook enabled, Webhook URL becomes required
    • Error shows: "Webhook URL is required when webhook is enabled."
  • Save Button State:
    • Disabled (gray) jika form invalid
    • Enabled (blue) jika all required fields filled correctly
    • Shows "Saving..." spinner during API call

Validation errors hanya muncul after field is touched (clicked/typed)

Edit Existing Owner (Same Form)

Form ini juga digunakan untuk edit mode:

  1. From Owner List, klik Edit button (pencil icon)
  2. Form terbuka dengan data existing owner pre-filled
  3. Header shows "Edit Owner" instead of "Create Owner"
  4. Breadcrumb shows "Edit" instead of "Create"
  5. Modify fields yang perlu diubah
  6. Klik "Update Owner" button (instead of "Save Owner")
  7. Success → redirect to Owner Detail View

Note: Edit mode loads existing data via API - may take 1-2 seconds loading

Scenario: Create Owner dengan Database Forwarding

    • Enable Webhook: OFF (they don't need real-time push)

      • Database: iot_analytics
      • Schema: telemetry
      • Credentials: (encrypted)

    • Save database config

Note: Database connection details diatur di Owner Detail View, bukan di create form

Scenario: Fix Validation Error (Missing Required Field)

Situasi: User tried to save but forgot required fields

What happens:

  • User fills Owner Name, Industry
  • Skips Contact Person (required)
  • Enters webhook URL dengan invalid format
  • Klik Save button → Nothing happens (button disabled)
  • User confused kenapa can't save

How to fix:

  1. Scroll through form
  2. Look for red borders (invalid fields)
  3. Find Contact Person field dengan red border
  4. Error message shows: "Contact person is required"
  5. Fill in contact person
  6. Check webhook URL - fix invalid format if needed
  7. Save button becomes enabled (blue)
  8. Klik Save → Success!

Tip: All validation errors are shown inline with red border + error message

Tips & Best Practices

Common Pitfalls:
  • Duplicate owner names: Backend rejects duplicate names - use unique identifiers
  • Invalid email format: Typos like "user@domain" (missing .com) cause validation errors
  • Webhook URL tanpa https: Use https:// for security, http:// may be blocked
  • Batch size too small: Setting 1-10 causes high database load - use 100-500 range
  • Enabling webhook without URL: Form validation blocks this - must provide URL
  • Wrong industry selection: Affects reporting/analytics - double check
  • Missing contact info: Makes support escalation difficult - always fill email/phone
Pro Tips:
  • Use descriptive names: "PT ADHI WATER" better than just "ADHI" - easier to identify
  • Prefix trial accounts: "TRIAL - Company Name" untuk easy filtering
  • Gold SLA as default: Unless specified otherwise, Gold is good balance
  • Fill notes field: Document contract details, special requirements, deadlines
  • Check payload preview: Before saving, verify JSON structure correct
  • Enable webhook early: Easier to configure during onboarding than retrofit later
  • Use higher batch size untuk analytics: 500-1000 untuk data warehouse scenarios
  • Use lower batch size untuk real-time: 50-100 untuk low-latency requirements
  • Document webhook endpoint: Add note about endpoint purpose/owner
  • Verify email before saving: Send test email untuk confirm address valid
  • Coordinate with client IT: Verify webhook endpoint accessible & firewall rules configured
