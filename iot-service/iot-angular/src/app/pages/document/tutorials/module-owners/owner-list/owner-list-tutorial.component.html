Apa itu Owner List?

Owner List adalah halaman untuk melihat dan mengelola semua Owner (pemilik/klien) yang terdaftar dalam sistem IoT.

Apa itu Owner?

Owner adalah perusahaan atau organisasi yang memiliki IoT devices dalam sistem. Setiap owner dapat memiliki multiple projects, nodes, dan sensors.

Fungsi Utama:
  • Melihat daftar lengkap semua owner
  • Monitor status owner (Active, Trial, Suspended)
  • Filter owner berdasarkan industry dan status
  • Search owner by nama, ID, atau kontak
  • Lihat summary resource setiap owner (projects, nodes, sensors)
  • Quick access ke detail owner

Cara Menggunakan

Filter Owner by Status
  1. Klik tab status yang diinginkan di bagian atas tabel
  2. Pilih salah satu:
    • All - Tampilkan semua owner
    • Active - Owner dengan akses penuh dan aktif
    • Trial - Owner dalam masa percobaan (limited time)
    • Suspended - Owner yang sementara ditangguhkan
  3. Tabel otomatis ter-filter sesuai status
  4. Badge angka menunjukkan jumlah owner per kategori
Tip: Gunakan filter status untuk quick monitoring, misalnya cek owner Trial yang perlu follow-up untuk convert ke Active.
Filter Owner by Industry
  1. Klik dropdown "Industry" di area filter
  2. Pilih jenis industri (contoh: Manufacturing, Water Treatment, Oil & Gas, dll)
  3. Tabel otomatis menampilkan owner dari industri tersebut
  4. Pilih "All Industry" untuk reset filter
Info: List industry di-generate otomatis dari data owner yang ada di sistem.
Search Owner
  1. Ketik di Search Box yang ada di sebelah kanan filter Industry
  2. Anda bisa search by:
    • Nama owner
    • ID owner
    • Kontak (person/email/phone)
  3. Hasil muncul secara real-time saat Anda mengetik
  4. Hapus text untuk reset search
Pro Tip: Kombinasikan filter Status + Industry + Search untuk hasil yang sangat spesifik!
Lihat Detail Owner
  1. Cari owner yang ingin dilihat detailnya
  2. Klik nama owner (link biru) di kolom "Owner"
  3. Anda akan diarahkan ke halaman Owner Detail
  4. Di halaman detail, Anda bisa lihat:
    • Informasi lengkap owner
    • List projects milik owner
    • Data forwarding configuration
    • User management
 Navigasi Pagination

Mengatur Rows per Page:

  1. Lihat dropdown "Rows" di bagian bawah tabel
  2. Pilih jumlah: 10, 20, atau 50
  3. Tabel akan reload dengan jumlah row sesuai pilihan

Navigasi Page:

  1. Gunakan button Previous / Next
  2. Atau klik nomor page langsung (1, 2, 3, ...)
  3. Info "Showing X to Y of Z owners" menunjukkan posisi data saat ini

Contoh Penggunaan

Scenario: Cari Owner Tertentu

Situasi: Anda ingin mencari owner "PT Adhi Water"

Langkah:

  1. Ketik Adhi di search box
  2. Hasil otomatis muncul dengan owner yang match
  3. Klik nama owner untuk lihat detail

Result: Quick access ke owner yang dicari tanpa scroll panjang

Scenario: Monitor Owner dengan Alert

Situasi: Anda perlu cek owner mana yang punya alert aktif

Langkah:

  1. Lihat kolom "Alerts" di tabel
  2. Cari angka merah (ada alert)
  3. Klik nama owner tersebut untuk investigasi
  4. Di halaman detail, cek alert yang perlu ditindaklanjuti

Result: Identifikasi cepat owner dengan masalah yang perlu perhatian

Scenario: Review Trial Owners untuk Follow-up

Situasi: Anda ingin follow-up owner Trial untuk convert ke Active

Langkah:

  1. Klik tab Trial
  2. Lihat list owner yang masih trial
  3. Check badge count untuk tahu berapa owner trial
  4. Review contact info untuk follow-up

Result: Sales team bisa fokus follow-up trial owners

Scenario: Export Data untuk Reporting

Situasi: Anda perlu data owner untuk laporan bulanan

Langkah:

  1. Filter sesuai kebutuhan (status/industry)
  2. Klik button "Export Owners"
  3. Download file Excel/CSV
  4. Gunakan data untuk reporting

Result: Data owner siap untuk analisis & reporting

Scenario: Filter Owner by Industry

Situasi: Anda ingin lihat semua owner dari industri Manufacturing

Langkah:

  1. Klik dropdown "Industry"
  2. Pilih Manufacturing
  3. Tabel otomatis filter owner Manufacturing saja
  4. Review resource stats (projects/nodes/sensors)

Result: Segmentasi owner by industry untuk analisis spesifik

Tips & Best Practices

Quick Tips:
  • Gunakan search untuk akses cepat ke owner tertentu
  • Badge angka di tab status = overview cepat distribusi owner
  • Alert merah = prioritas tinggi, perlu tindakan segera
  • Last Activity = monitoring aktivitas owner secara berkala
  • Kombinasi filter untuk hasil yang sangat spesifik
Perhatian:
  • Suspended owner tidak bisa akses sistem sama sekali
  • Trial owner punya batas waktu, follow-up sebelum expired
  • Alert perlu ditindaklanjuti segera untuk mencegah downtime
  • SLA level menentukan prioritas support yang diterima owner
Pro Tips:
  • Export data secara berkala untuk backup & analisis trend
  • Monitor trial owners weekly untuk conversion rate
  • Gunakan industry filter untuk segment-specific campaigns
  • Check alert count daily untuk proactive support
  • Review resource stats untuk capacity planning
