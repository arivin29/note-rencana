Apa itu Sensor Catalogs?

Sensor Catalogs adalah halaman untuk mengelola master database hardware sensor fisik yang digunakan dalam sistem IoT, termasuk konfigurasi RS485/Modbus register mapping, firmware package, calibration interval, dan metadata lainnya.

Apa itu Sensor Catalog?

Sensor Catalog adalah blueprint/template untuk specific hardware sensor model (contoh: HIRP RM-3D3Y Power Meter, DHT22 Temperature Sensor, Ultrasonic Level Sensor).

Setiap catalog berisi register map configuration yang mendefinisikan bagaimana cara membaca data dari hardware via RS485/Modbus protocol.

Kenapa Penting?
  • Plug & Play: Sensor baru bisa langsung dipake tanpa coding ulang firmware
  • Standardisasi: Satu model sensor = satu configuration, reusable untuk banyak device
  • Register Mapping: Define exact Modbus register addresses, data types, byte swap, dan unit conversion
  • Firmware Management: Track latest firmware version, changelog, dan download package
  • Calibration Tracking: Schedule periodic calibration based on manufacturer recommendation

Interface & Features

Interface Sensor Catalogs terdiri dari beberapa komponen utama:

Header Section
  • Search Box: Cari catalog by vendor name atau model name (realtime)
  • Add Catalog Button: Buka form untuk tambah sensor catalog baru
Data Table Columns
  • Model: Nama model sensor + icon asset, ID catalog (clickable untuk detail)
  • Vendor: Manufacturer/brand sensor (HIRP, DHT, Ultrasonic, etc)
  • Firmware: Latest firmware version & package link
  • Calibration: Interval hari untuk periodic calibration
  • Actions: Edit button (yellow), View detail button (blue)
Pagination Controls
  • Rows Dropdown: Pilih jumlah data per halaman (10, 20, 50)
  • Page Numbers: Navigasi antar halaman
  • Showing Info: Display range data yang sedang ditampilkan

Cara Menggunakan

Menambah Sensor Catalog Baru
  1. Klik tombol "Add Catalog" di kanan atas
  2. Drawer form akan muncul dari kanan
  3. Isi informasi catalog:
    • Model Name: Nama model sensor (contoh: "HIRP RM-3D3Y")
    • Vendor: Manufacturer (contoh: "HIRP")
    • Icon Asset: Bootstrap icon class (contoh: "bi bi-lightning-charge")
    • Firmware: Latest firmware version (contoh: "v2.1.0")
    • Calibration Interval: Dalam hari (contoh: 365 = 1 tahun)
    • Description: Deskripsi sensor & use case
  4. Upload/configure Register Map JSON (lihat detail di section berikutnya)
  5. Klik Save

Catalog baru akan muncul di list dan bisa langsung digunakan untuk assign sensor ke node

Melihat Detail Catalog
  1. Klik pada baris catalog (atau tombol View icon mata)
  2. Halaman detail akan terbuka menampilkan:
    • Basic Info: Model, vendor, firmware, calibration
    • Register Map Visualization: Table semua register yang didefinisikan
    • JSON Configuration: Raw JSON config untuk debugging/export

Detail view shows complete register map dengan kolom: Register, Type, Words, Swap, Unit, Label, Category

Edit Sensor Catalog
  1. Klik tombol Edit (icon pensil kuning) pada catalog
  2. Drawer form akan muncul dengan data existing pre-filled
  3. Modify field yang ingin diubah:
    • Update firmware version
    • Edit register map (add/remove/modify registers)
    • Adjust calibration interval
    • Change icon atau description
  4. Klik Save
Warning: Mengubah register map akan affect semua sensor yang menggunakan catalog ini. Test perubahan di development environment dulu sebelum apply ke production!

Memahami Register Map Configuration

Register Map adalah konfigurasi JSON yang mendefinisikan bagaimana membaca data dari sensor via RS485/Modbus protocol. Ini adalah "blueprint" komunikasi hardware.

JSON Structure
{{ '{' }}
  "version": 1,
  "baud_rate": 9600,
  "modbus_address": 1,
  "scan_interval_ms": 3000,
  "device_type": "HIRP-RM3D3Y",
  "description": "HIRP RM-3D3Y 3-Phase Power Meter",
  "registers": [
    {{ '{' }}
      "reg": 0,
      "type": "uint16",
      "words": 1,
      "swap": false,
      "unit": "V",
      "label": "Voltage L1",
      "category": "phase_L1"
    {{ '}' }},
    ...
  ]
{{ '}' }}
Top-Level Configuration
  • version: Schema version (currently 1)
  • baud_rate: RS485 baud rate (9600, 19200, 115200)
  • modbus_address: Default Modbus slave address (1-247)
  • scan_interval_ms: Berapa milidetik sekali baca sensor (3000 = 3 detik)
  • device_type: Unique identifier untuk catalog
  • description: Human-readable description
Register Array Fields
  • reg: Modbus register address (0-65535)
  • type: Data type - uint16, int16, uint32, int32, float32
  • words: Jumlah 16-bit words (1 untuk int16/uint16, 2 untuk int32/uint32/float32)
  • swap: Byte order swap - true untuk little-endian, false untuk big-endian
  • unit: Unit pengukuran (V, A, W, kWh, °C, %, etc)
  • label: Descriptive name untuk UI display
  • category: Grouping (phase_L1, phase_L2, energy, temperature, etc)

Contoh Penggunaan

Scenario: Add 3-Phase Power Meter Catalog

Situasi: Beli HIRP RM-3D3Y power meter baru, perlu setup catalog

Langkah:

  1. Klik "Add Catalog"
  2. Fill basic info:
    • Model: "HIRP RM-3D3Y"
    • Vendor: "HIRP"
    • Icon: "bi bi-lightning-charge"
    • Firmware: "v1.0.0"
    • Calibration: 365 days
  3. Configure register map (refer ke datasheet HIRP):
    • Voltage L1 at reg 0 (uint16)
    • Current L1 at reg 1 (uint16)
    • Active Power L1 at reg 2 (int16)
    • Energy Total at reg 7 (uint32, swap: true, words: 2)
    • ...17 more registers for L2, L3, dan energy counters
  4. Save catalog
  5. Assign catalog to gateway node yang punya RS485 interface

Result: Power meter data automatically parsed & displayed in telemetry dashboard

Scenario: Update Firmware Version

Situasi: HIRP release firmware v2.0 dengan bug fixes

Langkah:

  1. Search "HIRP RM-3D3Y" catalog
  2. Klik Edit
  3. Update Firmware field dari "v1.0.0" ke "v2.0.0"
  4. Add release notes di Description
  5. Save
  6. Notify users via alert system untuk upgrade firmware

Result: All devices using this catalog will see firmware update notification

Scenario: Fix Register Byte Swap Issue

Situasi: Energy counter reading salah, suspect byte order issue

Langkah:

  1. Find "Active Energy Total" register (reg 7, uint32)
  2. Klik Edit catalog
  3. Modify register: Change "swap": false to "swap": true
  4. Save dan monitor telemetry data
  5. If still wrong, revert back dan check datasheet lagi

Note: Byte swap biasanya diperlukan untuk uint32/int32 registers on some devices

Scenario: Add New Register to Existing Catalog

Situasi: Datasheet update, ada register baru untuk "Total Harmonic Distortion"

Langkah:

  1. Edit catalog
  2. Add new register entry di JSON: 
    {{ '{' }}
  "reg": 24,
  "type": "uint16",
  "words": 1,
  "swap": false,
  "unit": "%",
  "label": "THD Voltage L1",
  "category": "power_quality"
{{ '}' }}
  3. Save catalog
  4. Re-deploy firmware to devices (if needed)
  5. New data will appear in telemetry automatically

Result: Extended monitoring capability without hardware change

Scenario: Clone Catalog for Similar Device

Situasi: Beli Schneider PM5350 (mirip HIRP tapi beda vendor)

Langkah:

  1. Open HIRP catalog detail
  2. Copy JSON configuration
  3. Klik "Add Catalog" untuk buat baru
  4. Paste JSON, modify:
    • Model: "PM5350"
    • Vendor: "Schneider Electric"
    • device_type: "SCHNEIDER-PM5350"
    • Adjust register addresses (check Schneider datasheet)
  5. Save as new catalog

Tip: Cloning saves time untuk similar devices, tinggal adjust minor differences

Tips & Best Practices

Common Pitfalls:
  • Wrong byte swap: uint32 reads garbage → check datasheet byte order (big/little endian)
  • Register overlap: uint32 di reg 7 occupies reg 7 & 8 → jangan define reg 8 untuk data lain!
  • Too fast scan interval: scan_interval_ms < 1000 dapat overwhelm slow sensors
  • Hardcoded modbus address: Some devices allow changing address → use device-level override
  • Missing calibration: Sensors drift over time → set realistic calibration interval
Pro Tips:
  • Datasheet first: Always refer to official Modbus register map dari manufacturer
  • Test dengan Modbus tool: Use QModMaster atau similar untuk verify register map sebelum deploy
  • Versioning: Include firmware version in description untuk track compatibility
  • Categories: Use consistent category naming (phase_L1, phase_L2, energy) untuk easier grouping in UI
  • Scan interval tuning: Balance freshness vs bandwidth - 3000ms good default untuk most sensors
  • Backup catalogs: Export JSON configurations before major edits
  • Document units: Always specify correct unit (V, kV, mV) to avoid confusion
  • Icon consistency: Use relevant Bootstrap icons untuk easy visual identification

Quick Reference

Modbus Data Types
Type Words Range Use Case
uint16 1 0 to 65,535 Voltage, current, small counters
int16 1 -32,768 to 32,767 Power (can be negative), temperature
uint32 2 0 to 4,294,967,295 Energy counters (kWh), large values
int32 2 -2,147,483,648 to 2,147,483,647 Signed large values
float32 2 IEEE 754 High precision measurements
Common Register Categories
  • phase_L1, phase_L2, phase_L3 - 3-phase electrical measurements
  • energy - Energy counters (kWh, kvarh)
  • power_quality - THD, power factor, frequency
  • temperature - Temperature sensors
  • humidity - Humidity sensors
  • pressure - Pressure sensors
  • level - Ultrasonic/radar level sensors
  • flow - Flow meters
