Apa itu Node Models?

Node Models adalah halaman untuk mengelola metadata hardware device models (seperti ESP32, STM32, dll) yang digunakan dalam sistem IoT platform.

Apa itu Node Model?

Node Model adalah blueprint/template hardware device yang berisi informasi: vendor (Espressif, ST), hardware class (MCU/Gateway/Tracker), toolchain (ESP-IDF, Arduino), firmware repository, flash protocol, dan code generation support.

Fungsi Utama:
  • Melihat semua device models yang tersedia di platform
  • Add new device model untuk expand platform support
  • Edit existing model untuk update toolchain/firmware settings
  • Search models by vendor, toolchain, atau model code
  • View which models support automatic code generation
  • Manage firmware repository locations & build agents
Use Case: Ketika deploy node baru, Anda pilih Node Model (contoh: ESP32-DEVKIT-V1) yang kemudian menentukan firmware template, build process, dan flash protocol yang digunakan.

Cara Menggunakan

Search Node Models
  1. Ketik di Search Box
  2. Anda bisa search by:
    • Model Code: "ESP32", "STM32", dll
    • Vendor: "Espressif", "STMicroelectronics"
    • Toolchain: "ESP-IDF", "Arduino", "PlatformIO"
  3. Table otomatis filter real-time saat mengetik
  4. Hapus text untuk show all models
Tip: Search "ESP" untuk quick find semua ESP-based models!
Add New Node Model
  1. Klik button "Add Model" di kanan atas
  2. Drawer akan slide-in dari kanan
  3. Fill in form fields:
    • Model Code: Unique identifier (contoh: ESP32-C3-MINI)
    • Model Name: Descriptive name
    • Vendor: Manufacturer name
    • Hardware Class: Pilih MCU / Gateway / Tracker / Custom
    • Toolchain: Development toolchain name
    • Build Agent: Agent name untuk compile
    • Firmware Repo: Git URL atau path
    • Flash Protocol: Protocol untuk upload firmware (esptool, st-flash, dll)
    • Supports Codegen: ✅ if model support code generation
  4. Klik "Save"
  5. New model muncul di table
Note: Model Code harus unique! System akan reject jika duplicate.
Edit Existing Model
  1. Cari model yang ingin di-edit di table
  2. Klik button Edit (icon pensil kuning) di kolom Actions
  3. Drawer akan open dengan form pre-filled dengan data existing
  4. Update field yang diperlukan
  5. Klik "Save" untuk apply changes
  6. Table akan refresh dengan data terbaru
Common Edit: Update firmware repo URL ketika migrate ke repository baru atau update toolchain version.
View Model Details
  1. Pada table, cari model yang ingin dilihat
  2. Option 1: Klik pada Model Code (anywhere di row)
  3. Option 2: Klik button View (icon mata) di kolom Actions
  4. Navigate ke detail page dengan informasi lengkap:
    • Full model specifications
    • Associated firmware templates
    • Build configuration details
    • Deployment history (jika ada)
 Check Codegen Support

Lihat statistics di header:

5 / 12 model mendukung code generator

→ 5 models support automatic firmware code generation
→ 12 total models di system

Lihat per-model di table:

  • Badge Yes = Model support codegen
  • Badge No = Manual firmware development required
Pro Tip: Prefer models dengan codegen support untuk rapid deployment & easier maintenance!

│

Hardware Class Types:
Class Deskripsi Contoh Device
MCU Microcontroller / DevKit - single-board development platform ESP32 DevKit, Arduino Mega, STM32 Nucleo
Gateway Gateway devices - router/hub untuk collect data dari multiple sensors LoRa Gateway, WiFi Gateway, Cellular Gateway
Tracker GPS/location tracking devices dengan mobility features GPS Tracker, Asset Tracker, Vehicle Tracker
Custom Custom hardware tidak fit ke kategori lain Proprietary boards, hybrid devices
Common Toolchains:
ESP-IDF

For: ESP32, ESP8266 family
Type: Official Espressif framework
Language: C/C++

Arduino

For: Arduino boards, ESP32 (Arduino core)
Type: Easy-to-use framework
Language: C/C++ (simplified)

PlatformIO

For: Multi-platform support
Type: Unified build system
Language: C/C++

STM32Cube

For: STM32 microcontrollers
Type: ST official framework
Language: C/C++

Code Generation Support:
Yes Supports Codegen

Meaning: Platform dapat automatically generate firmware code untuk model ini

Benefits:

  • Faster deployment
  • Less manual coding
  • Standardized firmware structure
  • Easier maintenance
No Manual Development

Meaning: Firmware harus di-develop manually oleh developer

When Used:

  • Custom hardware requirements
  • Specialized functionality
  • Legacy device support
  • Prototype/experimental boards

Scenario: Add New ESP32 Model

Situasi: Company beli ESP32-C3 baru untuk project deployment

Langkah:

  1. Klik "Add Model"
  2. Fill form:
    • Model Code: ESP32-C3-DEVKIT
    • Model Name: ESP32-C3 Development Kit
    • Vendor: Espressif Systems
    • Hardware Class: MCU
    • Toolchain: ESP-IDF v5.1
    • Build Agent: esp32-builder-02
    • Firmware Repo: https://github.com/company/esp32-c3-fw
    • Flash Protocol: esptool
    • Supports Codegen: ✅ Yes
  3. Save → New model available untuk node deployment!

Result: ESP32-C3 model ready untuk deploy nodes

Scenario: Update Firmware Repository

Situasi: Team migrate firmware repository ke GitHub organization baru

Langkah:

  1. Search model yang perlu update (contoh: "ESP32")
  2. Klik Edit button pada model
  3. Update Firmware Repo field:
    • Old: https://github.com/oldorg/esp32-fw
    • New: https://github.com/neworg/esp32-fw
  4. Save changes
  5. Future firmware builds akan use new repository!

Result: Firmware repository updated untuk all future builds

Scenario: Check Codegen Compatible Models

Situasi: Planning new project, want to use models dengan automatic code generation

Langkah:

  1. Open Node Models page
  2. Check header statistics: "5 / 12 model mendukung code generator"
  3. Scan "Supports Codegen" column untuk badge Yes
  4. Filter by search (contoh: "ESP") untuk specific vendor
  5. Select model dengan codegen support untuk faster deployment
  6. Click view detail untuk confirm firmware template availability

Result: Identified best models untuk rapid project deployment

Scenario: Find Models by Toolchain

Situasi: Developer familiar dengan Arduino, want to use Arduino-based models

Langkah:

  1. Ketik Arduino di search box
  2. Table filtered untuk models using Arduino toolchain
  3. Review available options (ESP32 with Arduino, Arduino Mega, dll)
  4. Check hardware class untuk ensure fit dengan use case
  5. Select model dan proceed dengan deployment

Result: Found Arduino-compatible models untuk leverage existing expertise

Scenario: Add Custom Hardware

Situasi: Company develop proprietary IoT board untuk specific application

Langkah:

  1. Klik "Add Model"
  2. Fill form dengan custom specs:
    • Model Code: COMPANY-IOT-V1

Tips & Best Practices

Quick Tips:
  • Use descriptive Model Codes - include vendor & version (ESP32-C3-V1)
  • Keep firmware repos organized - separate repo per model family
  • Document toolchain versions untuk reproducible builds
  • Prefer models dengan codegen support untuk easier scaling
  • Test new models di staging environment before production use
  • Maintain consistent build agent naming conventions
Perhatian:
  • Model Code uniqueness: Cannot have duplicate codes - plan naming scheme carefully
  • Firmware repo access: Ensure build agents can access repositories (credentials, network)
  • Flash protocol compatibility: Must match actual hardware flashing method
  • Toolchain versions: Mismatched versions = build failures
  • Cannot delete models: If models sudah digunakan by deployed nodes (protect data integrity)
Pro Tips:
  • Create "template" models untuk common platforms (ESP32-TEMPLATE) untuk quick cloning
  • Use hardware class strategically untuk easy filtering (MCU for sensors, Gateway untuk hubs)
  • Document external dependencies di model name atau notes (WiFi required, BLE support, dll)
  • Setup CI/CD untuk firmware repos linked to models
  • Version firmware repos dengan tags (v1.0.0, v2.0.0) untuk rollback capability
  • Monitor codegen statistics - aim untuk high percentage untuk faster scaling
  • Keep vendor consistency - standardize vendor names (Espressif vs Espressif Systems)
