Apa itu Nodes?

Nodes (atau Devices) adalah perangkat IoT fisik yang terhubung ke sistem untuk mengirim telemetry data. Setiap node memiliki sensors yang mengukur parameter tertentu (temperature, humidity, pressure, dll).

Halaman Nodes List dengan filters, status badges, dan connectivity indicators

Node Components
  • Node Code: Unique identifier (e.g., NODE-001)
  • Node Model: Device type/model (ESP32, Arduino, Raspberry Pi)
  • Connectivity Status: Online, Degraded, Offline
  • Sensors: List of attached sensors (temperature, humidity, etc.)
  • Location: GPS coordinates atau installation address
  • Project Assignment: Which project this node belongs to
Kenapa Penting?
  • Device Management: Monitor health status semua devices dalam satu view
  • Quick Troubleshooting: Identify offline/degraded nodes untuk maintenance
  • Inventory Tracking: Keep track of all deployed IoT devices
  • Performance Monitoring: Check uptime, last seen, telemetry rate

Cara Akses Nodes List

Via Main Navigation
  1. Klik menu Nodes di sidebar kiri
  2. Nodes list page langsung terbuka
  3. Default: Show all nodes, sorted by most recent first
Via Dashboard Widget
  1. Di Dashboard, lihat widget "Node Health Trends"
  2. Klik node name untuk view detail
  3. Atau klik "View All Nodes" link
Via Project Detail
  1. Navigate ke Projects → Select Project
  2. Di Project Detail page, scroll ke section "Nodes in This Project"
  3. Klik node untuk view detail atau "View All"
Via Direct URL
http://localhost:4200/iot/nodes

Key Features

1. Node Filters
  • Owner Filter: Filter by specific owner/tenant
  • Project Filter: Filter by specific project (cascading from owner)
  • Status Filter: All / Online / Degraded / Offline
  • Model Filter: Filter by node model (ESP32, Arduino, etc.)
  • Location Filter: Filter by installation location
  • Search: Search by node code, name, atau serial number
2. Nodes Data Table

Nodes table dengan status indicators, sensors count, dan action buttons

Columns:

Column Description
Status Badge Color-coded: Online (green), Degraded (yellow), Offline (red)
Node Code Unique identifier (clickable link to detail)
Node Name Friendly name/label untuk node
Model Device model (ESP32-WROOM, Arduino Mega, etc.)
Project Project assignment (dengan owner badge)
Sensors Count Number of attached sensors (e.g., "5 sensors")
Last Seen Timestamp of last telemetry received
Uptime Percentage uptime (e.g., "98.5%")
Location Installation address atau GPS coordinates
Actions View Detail / Edit / Delete buttons
3. Node Actions
  • View Detail: Navigate to node detail page (sensors, telemetry, config)
  • Edit Node: Update node info (name, location, model)
  • Delete Node: Remove node (dengan confirmation)
  • Reboot: Send reboot command ke node (jika online)
  • View Telemetry: Quick link to node's telemetry data
  • Export CSV: Download nodes list ke CSV/Excel
4. Bulk Actions
  • Select Multiple: Checkbox untuk select multiple nodes
  • Bulk Delete: Delete multiple nodes sekaligus
  • Bulk Reboot: Reboot multiple nodes (hanya yang online)
  • Bulk Export: Export selected nodes ke CSV
  • Assign to Project: Move multiple nodes ke project lain

Pro Tips
  • Monitor Offline Nodes: Use Status Filter → Offline untuk quick identify problematic devices
  • Check Last Seen: Nodes dengan "Last Seen > 24h ago" likely need maintenance
  • Use Project Filter: For large deployments, filter by project untuk easier management
  • Export Regularly: Export nodes list monthly untuk inventory tracking
  • Bookmark Filters: Save filtered URLs untuk quick access (e.g., ?status=offline)
  • Check Uptime: Nodes dengan uptime < 95% mungkin ada connectivity issues
