View Telemetry Panduan menggunakan halaman Telemetry untuk memonitor sensor data streams

Apa itu Telemetry?

Telemetry adalah stream data real-time yang dikirim oleh sensors di Nodes (perangkat IoT) ke platform. Setiap telemetry record berisi timestamp, sensor value, channel info, dan metadata. Halaman Telemetry memungkinkan Anda melihat raw data logs, filter by owner/project/node/sensor, dan analyze sensor readings untuk monitoring dan troubleshooting.

Halaman Telemetry Logs dengan cascading filters, time range selector, dan telemetry data table

Komponen Telemetry Record
  • Timestamp: Waktu data received oleh platform (e.g., "2023-12-24 10:30:15")
  • Owner: Tenant yang memiliki node pengirim
  • Project: Project assignment dari node
  • Node: Perangkat IoT yang mengirim telemetry
  • Sensor: Sensor type yang measure data (e.g., DHT22, BME280)
  • Channel: Channel index (0 untuk single-channel, 0/1/2+ untuk multi-channel)
  • Value: Measured value (e.g., 28.5°C, 65%, 1013.25 hPa)
  • Unit: Unit of measurement (°C, %, kPa, ppm, etc.)
  • Quality: Data quality indicator (Good, Suspicious, Bad) based on range validation
Kenapa Penting?
  • Real-Time Monitoring: Track sensor readings as they arrive untuk immediate awareness
  • Troubleshooting: Identify anomalies atau out-of-range values yang trigger alerts
  • Historical Analysis: Review past data untuk trend analysis dan pattern recognition
  • Data Validation: Verify sensor accuracy by comparing expected vs actual values
  • Audit Trail: Maintain audit logs untuk compliance dan incident investigation

Cara Mengakses Telemetry Logs

4 Cara Akses Halaman Telemetry
  1. Via Main Navigation
    Klik menu Telemetry di sidebar kiri → Halaman Telemetry Logs terbuka → Tampil recent telemetry (default last 24 hours) dengan default sorting by timestamp (newest first)
  2. Via Dashboard Widget
    Dari Dashboard → Widget Telemetry Streams atau Ingestion & Forwarding → Klik "View All Telemetry" button → Navigate ke Telemetry Logs
  3. Via Node Detail
    Dari Nodes List → Select Node → Dalam Node Detail terdapat section "Recent Telemetry" → Klik "View All Telemetry" button (pre-filtered by node)
  4. Via Direct URL
    Akses langsung: http://localhost:4200/iot/telemetry

Fitur Telemetry Logs

1. Cascading Filters

Filter multi-level untuk mempersempit telemetry data:

  • Owner: Select tenant → Filters apply ke projects/nodes milik owner
  • Project: Select project (cascading from owner) → Filters ke nodes in project
  • Node: Select node (cascading from project) → Filters ke sensors attached to node
  • Sensor: Select sensor type (cascading from node) → Filters ke channels dari sensor
  • Channel: Select channel index (0, 1, 2+ untuk multi-channel sensors)
  • Time Range: Last 1 hour / 6 hours / 24 hours / 7 days / 30 days / Custom (date picker)
  • Quality: All / Good / Suspicious / Bad (based on range validation)

3. Auto-Refresh

Toggle auto-refresh untuk real-time monitoring:

  • Enable Auto-Refresh: Toggle switch di top-right → Data refresh every 5 seconds
  • Manual Refresh: Button "🔄 Refresh Now" untuk on-demand update
  • Last Updated: Timestamp last refresh (e.g., "Last updated: 10:30:25")
4. Export Telemetry

Download filtered telemetry data:

  • Export CSV: Download current filtered view sebagai CSV (max 10,000 records)
  • Export JSON: Download sebagai JSON untuk API integration atau custom analysis
  • Schedule Export: Setup scheduled exports (daily/weekly/monthly) untuk automated reporting
5. Quick Statistics

Summary statistics untuk filtered telemetry:

  • Total Records: Count telemetry records in filtered view
  • Average Value: Mean value untuk numeric sensors
  • Min/Max Value: Range dengan timestamps
  • Data Rate: Records per minute (telemetry ingestion rate)

Pro Tips
  • Use Cascading Filters: Start broad (Owner) → Narrow down (Project → Node → Sensor) untuk efficient data scoping
  • Monitor Quality Badge: Frequent "Bad" quality readings indicate sensor malfunction atau out-of-spec conditions needing attention
  • Time Range Best Practices: Use "Last 1 hour" untuk real-time troubleshooting, "Last 7 days" untuk trend analysis, "Last 30 days" untuk monthly reports
  • Export Before Analysis: For large datasets, export to CSV dan analyze di Excel/Python untuk better performance
  • Check Data Rate: Sudden drop in data rate (records/min) indicates node connectivity issues atau sensor failures
  • Bookmark Filters: Save filtered URLs untuk quick access ke specific monitoring views (e.g., ?node=NODE-001&sensor=TEMP&range=24h)
