Apa itu Alerts?

Alerts adalah notifikasi otomatis yang di-trigger ketika sensor values melewati threshold yang sudah dikonfigurasi. Alerts membantu Anda untuk quick detection of anomalies dan proactive issue resolution.

Halaman Alerts dengan filter, severity badges, dan action buttons

Alert Components
  • Alert Rule: Konfigurasi threshold dan condition (min/max value)
  • Triggered Alert: Event yang terjadi saat condition terpenuhi
  • Severity Level: Critical (red), Warning (yellow), Info (blue)
  • Status: Active (ongoing), Acknowledged (seen), Resolved (fixed)
  • Notification: Email, SMS, webhook, atau database forwarding
Kenapa Penting?
  • Early Warning: Detect issues sebelum jadi critical failures
  • Reduce Downtime: Quick response untuk minimize equipment downtime
  • Compliance: Meet regulatory requirements untuk safety monitoring
  • Cost Savings: Prevent expensive repairs dengan preventive maintenance

Cara Akses Alerts

Via Main Navigation
  1. Klik menu Alerts di sidebar kiri
  2. Alerts list page langsung terbuka
  3. Default: Show all active alerts, sorted by newest first
Via Dashboard Widget
  1. Di Dashboard, lihat widget "Top Anomalies" atau "Critical Alerts"
  2. Klik alert item untuk view detail
  3. Atau klik "View All Alerts" link
Via Direct URL
http://localhost:4200/iot/alerts

Key Features

1. Alert Filters
  • Severity Filter: All / Critical / Warning / Info
  • Status Filter: All / Active / Acknowledged / Resolved
  • Owner Filter: Filter by specific owner/tenant
  • Project Filter: Filter by specific project
  • Node Filter: Filter by specific node/device
  • Date Range: Filter by time period (Last 24h, 7d, 30d, Custom)
2. Alerts Data Table

Columns:

Column Description
Severity Badge: Critical (red), Warning (yellow), Info (blue)
Alert Title Alert name/description (clickable link to detail)
Sensor/Channel Source sensor channel yang trigger alert
Node Device/node name
Value Current sensor value yang trigger alert
Threshold Min/Max threshold yang di-exceed
Triggered At Timestamp when alert was triggered
Status Active / Acknowledged / Resolved
Actions Acknowledge / Resolve / View Detail buttons
3. Alert Actions
  • Acknowledge: Mark alert as "seen" (status → Acknowledged)
  • Resolve: Mark alert as "fixed" (status → Resolved)
  • View Detail: Navigate to alert detail page dengan full history
  • Bulk Actions: Select multiple alerts, acknowledge/resolve semua sekaligus
  • Export: Download alerts data ke CSV/Excel

Pro Tips
  • Prioritize Critical: Always handle Critical alerts first (red badges)
  • Acknowledge Quickly: Mark alerts as acknowledged untuk track yang sudah dilihat
  • Root Cause Analysis: Click "View Detail" untuk see alert history & patterns
  • Set Notifications: Configure email/SMS untuk critical alerts
  • Regular Review: Check alerts daily untuk stay on top of issues
