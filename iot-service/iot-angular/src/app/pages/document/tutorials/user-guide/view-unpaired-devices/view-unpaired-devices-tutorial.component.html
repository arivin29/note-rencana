View Unpaired Devices Panduan menggunakan halaman Unpaired Devices untuk pairing device baru ke sistem

Apa itu Unpaired Devices?

Unpaired Devices adalah perangkat IoT (Nodes) yang sudah terdeteksi oleh platform tetapi belum di-assign ke project manapun. Device baru yang baru saja dinyalakan pertama kali akan muncul di list ini dan menunggu untuk "dipasangkan" (paired) ke project tertentu agar dapat mulai berfungsi dalam sistem.

Halaman Unpaired Devices dengan device list, device info, dan pairing actions

Komponen Unpaired Device
  • Device MAC Address: Unique hardware address (e.g., AA:BB:CC:DD:EE:FF)
  • Device Model: Type perangkat (ESP32-WROOM, Arduino Mega, Raspberry Pi)
  • Serial Number: Manufacturer serial number (optional, jika tersedia)
  • First Seen: Timestamp pertama kali device detected oleh platform
  • Last Seen: Timestamp last heartbeat/ping dari device
  • Status: Pending (waiting pairing) / Ready (ready to pair) / Offline (tidak terdeteksi > 5 min)
  • Firmware Version: Installed firmware version (untuk compatibility check)
Kenapa Penting?
  • Device Onboarding: Streamline proses add devices baru ke sistem tanpa manual configuration
  • Auto-Discovery: Platform automatically detect devices yang connect ke network
  • Security: Admin review dan approve devices sebelum granted access ke production projects
  • Inventory Tracking: Monitor devices yang belum deployed untuk inventory management
  • Bulk Pairing: Pair multiple devices sekaligus untuk large-scale deployments

Cara Mengakses Unpaired Devices

3 Cara Akses Halaman Unpaired Devices
  1. Via Main Navigation
    Klik menu Unpaired Devices di sidebar kiri (biasanya di section "Device Management") → Halaman Unpaired Devices List terbuka → Tampil semua devices yang belum paired dengan sorting by first seen (newest first)
  2. Via Dashboard Widget
    Dari Dashboard → Widget Unpaired Devices (jika available) → Klik "View All Unpaired" button → Navigate ke Unpaired Devices List
  3. Via Direct URL
    Akses langsung: http://localhost:4200/iot/unpaired-devices
Permission Required

Note: Only users dengan role Admin atau Device Manager yang dapat access halaman Unpaired Devices dan perform pairing actions. Regular users tidak dapat pair devices untuk security reasons.

Fitur Unpaired Devices

1. Device Filters

Filter untuk mempersempit daftar unpaired devices:

  • Status: All / Ready / Pending / Offline (devices tidak terdeteksi > 5 minutes)
  • Device Model: Filter by hardware type (ESP32, Arduino, Raspberry Pi, etc.)
  • First Seen: Filter by date range (Today / Last 7 days / Last 30 days / Custom)
  • Search: Cari by MAC Address atau Serial Number
2. Unpaired Devices Data Table

Tabel menampilkan semua unpaired devices dengan columns berikut:

Column Description
Status Badge Color-coded: Ready (online, siap pair), Pending (waiting init), Offline (no heartbeat)
MAC Address Unique hardware identifier (e.g., AA:BB:CC:DD:EE:FF)
Device Model Hardware type dengan icon (e.g., 📟 ESP32-WROOM, 🔧 Arduino Mega)
Serial Number Manufacturer SN (jika tersedia, otherwise "N/A")
First Seen Timestamp pertama detected (e.g., "2023-12-24 08:15:30")
Last Seen Last heartbeat timestamp (relative time: "2 minutes ago")
Firmware Version (e.g., "v1.2.3") dengan compatibility badge (✅ Compatible / ⚠️ Update Needed)

3. Pairing Process

Steps untuk pair device ke project:

  1. Select Device: Klik button "Pair Device" pada device yang ingin paired → Modal dialog terbuka dengan pairing form
  2. Assign Owner: Select Owner (tenant) dari dropdown → Determines project list yang available
  3. Select Project: Choose Project dari dropdown (cascading from owner) → Device akan di-assign ke project ini
  4. Set Node Info: Fill device information:
    • Node Code: Auto-generated (e.g., NODE-001) atau manual input
    • Node Name: Friendly name (e.g., "Temperature Sensor - Room 101")
    • Location: Installation address atau GPS coordinates (optional)
    • Description: Purpose dan notes (optional)
  5. Configure Sensors: Review detected sensors dan configure channels:
    • Platform automatically detect attached sensors (e.g., DHT22 → 2 channels: Temperature & Humidity)
    • Assign sensor types to channels (from sensor catalog)
    • Set calibration offsets jika needed (e.g., +0.5°C correction)
  6. Submit Pairing: Klik "Pair Device" button → Device moved dari Unpaired Devices list ke Nodes List → Status updated ke "Online" → Mulai send telemetry
4. Bulk Pairing

Pair multiple devices sekaligus untuk large deployments:

  • Select Multiple: Checkbox di tiap row untuk select devices dengan same configuration
  • Bulk Pair: Button "Bulk Pair" → Modal opens with shared configuration:
    • Assign same Owner & Project
    • Auto-generate Node Codes (NODE-001, NODE-002, etc.)
    • Apply same Location (e.g., "Factory Floor A")
    • Same sensor configuration (if devices identical)
  • Review & Confirm: Preview list with generated codes → Confirm → Bulk pairing executed
5. Ignore Devices

Untuk devices yang tidak ingin paired (e.g., test devices, unauthorized devices):

  • Ignore Device: Klik "Ignore" button → Device removed dari Unpaired Devices list → Moved ke "Ignored Devices" list (accessible di settings)
  • Re-enable: Dari Ignored Devices list, dapat re-enable device untuk bring back ke Unpaired list
  • Security: Ignoring prevents unauthorized devices dari auto-pairing

Pro Tips
  • Pair Quickly: Devices yang "First Seen" sudah > 24 hours ago mungkin test devices atau forgotten devices yang perlu reviewed
  • Check Firmware: Always verify firmware compatibility sebelum pairing. Devices dengan firmware version terlalu lama (⚠️ Update Needed badge) should be updated first
  • Descriptive Names: Use naming convention yang consistent (e.g., "[Location] - [Sensor Type]") untuk easier management di Nodes List
  • Bulk Pairing Efficiency: For large deployments (e.g., 50+ identical devices di same location), use bulk pairing feature untuk save time (estimated: 5 seconds per device manual vs 30 seconds batch for 10 devices)
  • Monitor Last Seen: Devices dengan "Offline" status (Last Seen > 5 min ago) mungkin memiliki connectivity issues atau powered off, should investigate sebelum pairing
  • Security Review: Regularly review Unpaired Devices list untuk detect unauthorized devices (e.g., unknown MAC addresses). Use "Ignore" feature untuk block suspicious devices
