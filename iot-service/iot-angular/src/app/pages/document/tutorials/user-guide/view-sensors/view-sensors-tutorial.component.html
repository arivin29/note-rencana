View Sensors Panduan menggunakan halaman Sensors untuk memonitor sensor types dan specifications

Apa itu Sensors?

Sensors adalah komponen yang attached ke Nodes (perangkat IoT) untuk mengukur parameter fisik seperti suhu, kelembaban, tekanan, getaran, dll. Setiap sensor memiliki spesifikasi yang menentukan range pengukuran, akurasi, dan unit of measurement. Halaman Sensors memungkinkan Anda melihat catalog semua sensor types yang tersedia dalam sistem dan spesifikasinya.

Halaman Sensors Catalog dengan sensor types, specifications, dan channel details

Komponen Sensor
  • Sensor Type: Kategori sensor (e.g., Temperature, Humidity, Pressure)
  • Sensor Code: Identifier unik (e.g., TEMP-DHT22, HUMID-BME280)
  • Sensor Name: Nama deskriptif (e.g., "DHT22 Temperature Sensor")
  • Unit of Measurement: Satuan ukur (°C, %, kPa, m/s²)
  • Min/Max Range: Range pengukuran valid (-40°C to 80°C)
  • Accuracy: Akurasi sensor (±0.5°C, ±2%)
  • Channels: Jumlah channel output (single channel atau multi-channel)
  • Formula: Rumus konversi raw value → actual value (optional)
Kenapa Penting?
  • Sensor Selection: Pilih sensor yang tepat untuk use case Anda berdasarkan spesifikasi
  • Calibration: Pahami range dan akurasi untuk kalibrasi yang akurat
  • Data Validation: Validasi telemetry data berdasarkan min/max range sensor
  • Troubleshooting: Identifikasi sensor yang menghasilkan out-of-range readings
  • Documentation: Reference catalog untuk dokumentasi sistem

Cara Mengakses Sensors Catalog

3 Cara Akses Halaman Sensors
  1. Via Main Navigation
    Klik menu Sensors di sidebar kiri → Halaman Sensors Catalog terbuka → Tampil semua sensor types dengan default sorting by category
  2. Via Node Detail
    Dari Nodes List → Select Node → Dalam Node Detail terdapat section "Attached Sensors" → Klik sensor name untuk lihat specifications OR "View Sensor Catalog"
  3. Via Direct URL
    Akses langsung: http://localhost:4200/iot/sensors

Fitur Sensors Catalog

1. Sensor Filters

Filter untuk mempersempit daftar sensors:

  • Sensor Type: Filter by category (Temperature, Humidity, Pressure, Gas, Motion, Light, Sound, etc.)
  • Unit: Filter by unit of measurement (°C, %, kPa, ppm, lux, dB)
  • Channels: Single-channel atau Multi-channel
  • Search: Cari by Sensor Code, Name, atau Description
2. Sensors Data Table

Tabel menampilkan semua sensor types dengan columns berikut:

Column Description
Sensor Code Unique identifier (clickable link ke Sensor Detail)
Sensor Name Friendly name (e.g., "DHT22 Temperature & Humidity Sensor")
Type Category dengan icon: 🌡️ Temperature, 💧 Humidity, 📊 Pressure, etc.
Unit Unit of measurement (°C, %, kPa, ppm, m/s², lux, dB)
Min Range Minimum measurement value (e.g., -40°C, 0%, 300 hPa)
Max Range Maximum measurement value (e.g., 80°C, 100%, 1100 hPa)
Accuracy Sensor accuracy (e.g., ±0.5°C, ±2%, ±1 hPa)
Channels Number of output channels (e.g., 1 for single, 2+ for multi)
Nodes Using Count nodes yang attached sensor ini (clickable link ke Nodes filtered by sensor)

3. Sensor Detail

Klik Sensor Code atau "View Detail" untuk melihat:

  • Full Specifications: Detailed specs (range, accuracy, resolution, response time)
  • Channel Mapping: Jika multi-channel, tampil mapping tiap channel (e.g., Channel 0: Temperature, Channel 1: Humidity)
  • Formula: Conversion formula jika ada (e.g., celsius = (rawValue - 32) * 5/9)
  • Calibration Info: Calibration offset/multiplier jika configured
  • Nodes List: List nodes yang attached sensor ini dengan status connectivity
  • Recent Telemetry: Sample recent readings dari sensor ini
4. Sensor Types Categories

Katalog sensor types yang tersedia:

  • 🌡️ Temperature: DHT22, DS18B20, BME280 (range: -40°C to 125°C)
  • 💧 Humidity: DHT11, SHT31 (range: 0% to 100% RH)
  • 📊 Pressure: BMP280, MPL3115A2 (range: 300 hPa to 1100 hPa)
  • 💨 Gas: MQ-2 (smoke), MQ-135 (air quality), CCS811 (CO₂, TVOC)
  • 🏃 Motion: PIR (presence), MPU6050 (accelerometer/gyroscope)
  • 💡 Light: BH1750, TSL2561 (range: 1 lux to 65535 lux)
  • 🔊 Sound: KY-038 (sound level in dB)
  • 📏 Distance: HC-SR04 (ultrasonic, range: 2cm to 400cm)
  • ⚡ Current/Voltage: INA219, ACS712

Pro Tips
  • Check Accuracy: Pilih sensors dengan accuracy sesuai requirement (industrial: ±0.1°C, general: ±0.5°C sufficient)
  • Verify Range: Pastikan sensor range cover expected conditions (e.g., outdoor temperature sensor: -20°C to 50°C di Indonesia)
  • Multi-Channel Efficiency: Gunakan multi-channel sensors (e.g., BME280: temp + humidity + pressure) untuk reduce node complexity dan cost
  • Calibration: Sensors yang menunjukkan drift (offset dari expected value) perlu re-calibration atau replacement
  • Unit Consistency: Ensure semua sensors untuk parameter yang sama use consistent units (e.g., semua temperature in °C, jangan mix dengan °F)
