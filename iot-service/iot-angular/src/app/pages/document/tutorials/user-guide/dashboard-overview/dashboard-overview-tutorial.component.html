Apa itu IoT Dashboard?

IoT Dashboard adalah halaman utama untuk monitoring real-time semua IoT devices, sensors, dan telemetry data dalam satu tampilan. Dashboard menampilkan KPI cards, charts, statistics, dan widget-widget interaktif untuk memberikan overview lengkap sistem IoT.

Dashboard utama dengan System Overview, Node Health Trends, Platform Statistics, dan widgets lainnya

Dashboard Layout

Dashboard terbagi menjadi beberapa widget section yang masing-masing menampilkan data specific:

  • Filter Section: Owner & Project filters dengan time range selector (24h/7d/30d)
  • System Overview: 4 KPI metrics (Active Nodes, Online Sensors, Critical Alerts, Data Throughput)
  • Node Health Trends: Line chart showing node status over time (Online/Degraded/Offline)
  • Platform Statistics: Total counts dengan breakdown (Owners, Projects, Nodes, Sensors)
  • Top Anomalies: List of nodes dengan critical alerts
  • Ingestion & Forwarding: Telemetry rate dan forwarding success rate
  • Recent Activities: Timeline of recent events
  • IoT Logs Stats: Log statistics (Total logs, Active channels, Error rate)
Kenapa Penting?
  • Single Pane of Glass: Lihat semua metrics penting dalam satu halaman
  • Real-Time Monitoring: Data di-refresh secara berkala untuk monitoring live
  • Quick Health Check: Identify issues dengan color-coded status (green/yellow/red)
  • Contextual Filters: Filter by Owner/Project untuk melihat data specific tenant
  • Drill-Down Navigation: Klik widgets untuk navigate ke detail pages
  • Time-Based Analysis: Compare metrics across 24h, 7d, atau 30d time ranges

Cara Akses Dashboard

Ada beberapa cara untuk mengakses Dashboard:

Via Main Navigation (Recommended)
  1. Klik menu Dashboard di sidebar kiri
  2. Atau navigate via breadcrumb: IoT → Dashboard
  3. Dashboard page langsung terbuka
  4. Default: No filters (show all data), time range = 24h
Via Direct URL

Akses langsung via browser:

http://localhost:4200/iot/dashboard
Default Behavior

Saat pertama kali membuka Dashboard:

  • Filters: Tidak ada filter (show all owners/projects)
  • Time Range: 24 hours (default)
  • Auto-Refresh: Tidak aktif (manual refresh saja)
  • View: Global view (semua data dari semua tenants jika Super Admin)

Key Features & Widgets

Dashboard memiliki 8 widget utama yang masing-masing punya fungsi spesifik:

1. Owner & Project Filters

Fungsi: Filter semua widgets by Owner atau Project specific

  • Owner Dropdown: Select specific owner (cascading: auto-load projects milik owner)
  • Project Dropdown: Select specific project (depends on owner filter)
  • Time Range Selector: 24h (Last 24 hours) / 7d (Last 7 days) / 30d (Last 30 days)
  • Apply Button: Klik untuk apply filters ke semua widgets

Semua widgets akan refresh dan menampilkan data sesuai filter yang dipilih

2. System Overview (4 KPI Cards)

Fungsi: Tampilkan 4 metrics utama dengan trend indicators

Metric Description Trend
Active Nodes Total nodes dengan status "Online" ↑ ↓ → (Up/Down/Flat)
Online Sensors Total sensors yang sedang aktif ↑ ↓ → (Up/Down/Flat)
Critical Alerts Active alerts dengan severity "critical" Red badge (high priority)
Data Throughput Telemetry ingestion rate (data points/min) ↑ ↓ → (Up/Down/Flat)
3. Node Health Trends (Line Chart)

Fungsi: Visualisasi node status over time (time-series chart)

  • 3 Lines: Online (green), Degraded (yellow), Offline (red)
  • X-Axis: Time (per hour dalam 24h, per day dalam 7d/30d)
  • Y-Axis: Count of nodes per status
  • Hover: Tooltip menampilkan exact count pada waktu tertentu
  • Legend: Status summary (total count per status)
4. Platform Statistics (Breakdown Cards)

Fungsi: Tampilkan total counts dengan percentage breakdown

  • Total Owners: Active/Suspended breakdown
  • Total Projects: Active/Archived breakdown
  • Total Nodes: Online/Degraded/Offline breakdown
  • Total Sensors: Active/Faulty/Calibration Due breakdown

Color-coded: Green (good), Yellow (warning), Red (critical)

5. Top Anomalies (Critical Nodes List)

Fungsi: List of nodes dengan most critical alerts

  • Node Name: Link to node detail page
  • Status: Current health status (Degraded/Offline/Critical)
  • Active Alerts: Count of alerts (Critical/Warning)
  • Last Seen: Timestamp of last telemetry data received
6. Ingestion & Forwarding (Rate Metrics)

Fungsi: Monitor telemetry ingestion dan forwarding success rate

  • Ingestion Rate: Telemetry data points per minute (sparkline chart)
  • Forwarding Success: Webhook/Database forwarding success percentage
  • Failed Deliveries: Count of failed forwarding attempts
  • Trend: Increase/Decrease indicator
7. Recent Activities (Event Timeline)

Fungsi: Timeline of recent system events

  • Event Type: Node registered, Alert triggered, Config changed, etc.
  • Timestamp: When event occurred (relative time: "2 hours ago")
  • Description: Brief description of the event
  • Icon: Color-coded icon based on event severity
8. IoT Logs Stats (Log Summary)

Fungsi: Summary statistik untuk raw IoT logs

  • Total Logs: Count of all log entries in time range
  • Active Channels: Number of sensor channels yang generating logs
  • Error Rate: Percentage of logs dengan error status
  • Last Update: Timestamp of most recent log entry

Pro Tips
  • Use Filters Wisely: Start dengan no filters untuk see global view, lalu apply specific owner/project filter untuk drill-down
  • Monitor Trends: Check trend indicators (↑↓→) pada KPI cards untuk identify increasing/decreasing patterns
  • Time Range Context: 24h untuk real-time monitoring, 7d untuk weekly analysis, 30d untuk monthly reports
  • Critical Alerts First: Always check Top Anomalies widget untuk identify urgent issues yang perlu immediate action
  • Drill-Down Navigation: Klik node names atau chart elements untuk navigate ke detail pages
  • Refresh Regularly: Dashboard tidak auto-refresh, gunakan browser refresh (F5) untuk update data
