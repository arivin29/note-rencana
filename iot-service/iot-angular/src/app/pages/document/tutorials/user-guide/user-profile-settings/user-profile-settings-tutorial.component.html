Apa itu User Profile Settings?

User Profile Settings adalah halaman untuk mengelola informasi profil user dan keamanan akun. Di sini Anda bisa update nama, email, nomor telepon, dan mengganti password untuk meningkatkan keamanan akun.

Halaman User Profile dengan form untuk update informasi personal

Fitur Utama
  • Update Profile: Edit nama lengkap, email, dan nomor telepon
  • Change Password: Ganti password lama dengan yang baru
  • Profile Picture: Upload atau ganti foto profil (jika tersedia)
  • Role Information: View role Anda (User, Admin, Owner, Super Admin)
  • Account Status: Check status akun (Active/Suspended)
Kenapa Penting?
  • Security: Regularly update password untuk keamanan akun
  • Contact Info: Pastikan email & phone number up-to-date untuk notifikasi alerts
  • Professional Identity: Nama lengkap yang jelas memudahkan kolaborasi tim
  • Account Management: Monitor role & permissions untuk memahami access level

Cara Akses Profile Settings

Ada beberapa cara untuk mengakses Profile Settings:

Via Top Navigation Bar (Recommended)
  1. Klik profile icon/avatar di pojok kanan atas (next to notification bell)
  2. Dropdown menu akan muncul
  3. Klik menu "Profile Settings" atau "My Profile"
  4. Halaman Profile Settings langsung terbuka
Via Direct URL

Akses langsung via browser:

http://localhost:4200/iot/profile

URL bisa berbeda tergantung routing configuration

First-Time Access

Saat pertama kali login, sistem mungkin redirect ke Profile Settings untuk:

  • Complete profile information (jika masih kosong)
  • Change default password (jika account baru dibuat admin)
  • Accept terms & conditions

Key Features

Profile Settings page memiliki beberapa section penting:

1. Update Profile Information

Form Fields:

Field Description Required
Full Name Nama lengkap user (displayed di header & logs) ✅ Yes
Email Email address untuk login & notifications ✅ Yes
Phone Number Nomor telepon untuk SMS alerts (jika enabled) ❌ Optional
Role User role (User/Admin/Owner/Super Admin) 🔒 Read-only
Status Account status (Active/Suspended) 🔒 Read-only

Klik Save Changes button untuk update profile

2. Change Password

Password Form Fields:

Form Change Password dengan validasi current password

Field Description Validation
Current Password Password lama yang sedang digunakan Must match existing password
New Password Password baru yang ingin digunakan Min 8 characters, uppercase, lowercase, number
Confirm New Password Konfirmasi password baru Must match new password
Password Requirements
  • Minimum 8 characters
  • At least 1 uppercase letter (A-Z)
  • At least 1 lowercase letter (a-z)
  • At least 1 number (0-9)
  • At least 1 special character (@, #, $, %, etc.) - Optional
3. Profile Picture Upload (Optional)

Fungsi: Upload atau ganti foto profil

  • File Format: JPG, PNG, atau GIF
  • Max Size: 2MB per file
  • Recommended Size: 200x200 pixels (square ratio)
  • Upload Button: Click "Choose File" atau drag & drop image
  • Preview: Image preview sebelum save

Foto profil akan muncul di header, comments, dan activity logs

Pro Tips
  • Regular Password Updates: Ganti password setiap 3-6 bulan untuk keamanan
  • Strong Passwords: Use password manager untuk generate strong passwords
  • Email Verification: Pastikan email valid untuk receive alert notifications
  • Phone Number: Add phone number jika ingin receive SMS alerts
  • Profile Picture: Upload professional photo untuk better team collaboration
  • Don't Share: Never share password dengan siapapun, termasuk admin
