View Projects Panduan menggunakan halaman Projects untuk mengelola project IoT Anda

Apa itu Projects?

Projects adalah container logis untuk mengelompokkan beberapa Nodes (perangkat IoT) yang terkait dalam satu kesatuan proyek. Misalnya, jika Anda menginstal perangkat IoT di beberapa lokasi berbeda (Gedung A, Gudang B, Pabrik C), masing-masing dapat diorganisir dalam project terpisah untuk memudahkan manajemen.

Halaman Projects List dengan filters, project cards, dan node counts

Komponen Project
  • Project Code: Identifier unik project (e.g., PROJ-001)
  • Project Name: Nama deskriptif (e.g., "Smart Building HQ")
  • Owner: Tenant yang memiliki project
  • Nodes: Jumlah perangkat yang assigned ke project
  • Location: Lokasi fisik instalasi (alamat atau GPS)
  • Status: Active, Inactive, Archived
  • Description: Deskripsi tujuan project
Kenapa Penting?
  • Organisasi Efisien: Kelompokkan devices berdasarkan lokasi, fungsi, atau department
  • Permission Management: Assign user access per-project untuk control granular
  • Reporting: Generate laporan telemetry dan statistik per-project
  • Maintenance Scheduling: Jadwalkan maintenance devices berdasarkan project lifecycle
  • Budgeting: Track biaya operasional dan ROI per-project

Cara Mengakses Projects

4 Cara Akses Halaman Projects
  1. Via Main Navigation
    Klik menu Projects di sidebar kiri → Halaman Projects List terbuka → Tampil semua projects dengan default sorting by created date (newest first)
  2. Via Dashboard Widget
    Dari Dashboard → Widget Platform Statistics → Klik "Projects" card → Navigate ke Projects List OR klik "View All Projects" button
  3. Via Owner Detail
    Klik Owners menu → Select Owner → Dalam Owner Detail terdapat section "Projects in This Owner" → Klik project name untuk detail OR "View All Projects"
  4. Via Direct URL
    Akses langsung: http://localhost:4200/iot/projects

Fitur Projects

1. Project Filters

Filter untuk mempersempit daftar projects:

  • Owner: Filter by tenant/owner (multi-tenant support)
  • Status: All / Active / Inactive / Archived
  • Location: Filter by installation location
  • Created Date: Filter by date range (Last 7 days / 30 days / Custom)
  • Search: Cari by Project Code, Name, atau Description
2. Projects Data Table

Tabel menampilkan semua projects dengan columns berikut:

Column Description
Status Badge Color-coded badge: Active (green), Inactive (gray), Archived (yellow)
Project Code Unique identifier (clickable link ke Project Detail)
Project Name Friendly name (e.g., "Smart Building HQ", "Factory Monitoring")
Owner Tenant yang memiliki project (dengan badge owner code)
Nodes Count Jumlah nodes assigned (clickable link ke Nodes filtered by project)
Location Physical location (address atau GPS coordinates)

3. Project Actions
  • View Detail: Klik Project Code atau button "View Detail" → Navigate ke Project Detail Page (tampil project info, nodes list, telemetry summary, alerts)
  • Edit Project: Update Project Name, Description, Location, Status
  • Delete Project: Hapus project (dengan confirmation, hanya jika tidak ada nodes)
  • Archive Project: Set status ke "Archived" (retain data, tidak aktif di dashboard)
  • View Nodes: Quick link ke Nodes List filtered by project
  • Export CSV: Download projects list sebagai CSV untuk reporting
4. Create New Project

Klik button "+ New Project" di top-right untuk membuat project baru:

  • Project Code: Auto-generated (e.g., PROJ-001) atau manual input
  • Project Name: Required (e.g., "Smart Office Jakarta")
  • Owner: Select dari dropdown owners (required)
  • Location: Address atau GPS coordinates (optional)
  • Description: Tujuan dan scope project (optional)
  • Status: Active (default) / Inactive
5. Bulk Actions

Kelola beberapa projects sekaligus:

  • Select Multiple: Checkbox di tiap row untuk select multiple projects
  • Bulk Archive: Archive selected projects sekaligus
  • Bulk Export: Export selected projects to CSV
  • Bulk Change Owner: Transfer multiple projects ke owner lain (admin only)

Pro Tips
  • Organize by Location: Create separate projects untuk tiap lokasi fisik (e.g., "Jakarta Office", "Surabaya Warehouse") untuk maintenance yang lebih efisien
  • Archive Completed Projects: Jangan delete project yang sudah selesai, gunakan status "Archived" untuk retain historical data
  • Monitor Last Activity: Projects dengan "Last Activity > 7 days ago" mungkin memiliki node connectivity issues
  • Use Descriptive Names: Gunakan naming convention yang jelas (e.g., "[Location] - [Purpose]" seperti "Jakarta - Temperature Monitoring")
  • Regular Exports: Export projects list quarterly untuk inventory auditing dan budgeting reports
  • Check Nodes Count: Projects dengan 0 nodes mungkin perlu setup atau archiving
  • Bookmark Filters: Save filtered URLs untuk quick access (e.g., ?owner=OWNER-001&status=active)
