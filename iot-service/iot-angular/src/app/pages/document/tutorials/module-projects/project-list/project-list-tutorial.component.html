Apa itu Project List?

Project List adalah halaman untuk melihat dan mengelola semua Project yang ada dalam sistem IoT dengan tampilan card view yang informatif.

Apa itu Project?

Project adalah unit deployment IoT devices yang dimiliki oleh satu Owner. Setiap project berisi multiple nodes dan sensors yang deploy di satu lokasi atau area tertentu.

Fungsi Utama:
  • Melihat semua project dalam card view yang informatif
  • Monitor status project (Active, Maintenance, Offline)
  • Filter project berdasarkan owner dan status
  • Search project by nama, ID, atau lokasi
  • Lihat summary resource setiap project (nodes, sensors, alerts)
  • Quick access ke detail project, nodes, dan telemetry

Cara Mengakses

Sidebar Menu IoT Projects
Role Access: Halaman ini dapat diakses oleh Super Admin, Admin, dan Owner

Cara Menggunakan

Filter Project by Status
  1. Klik tab status yang diinginkan di bagian atas
  2. Pilih salah satu:
    • All - Tampilkan semua project
    • Active - Project yang aktif dan operational
    • Maintenance - Project sedang dalam maintenance
    • Offline - Project yang offline/tidak aktif
  3. Cards otomatis ter-filter sesuai status
  4. Badge angka menunjukkan jumlah project per kategori
Tip: Gunakan filter "Maintenance" untuk cek project yang sedang maintenance agar bisa schedule dengan baik.
Filter Project by Owner
  1. Klik dropdown "Owner" di area filter
  2. Pilih owner (contoh: PT ABC, PT XYZ, dll)
  3. Cards otomatis menampilkan project dari owner tersebut
  4. Pilih "All Owners" untuk reset filter
Info: Owner dropdown di-populate otomatis dari semua owner yang ada di sistem.
Search Project
  1. Ketik di Search Box
  2. Anda bisa search by:
    • Nama project
    • ID project
    • Lokasi project
  3. Hasil muncul setelah 400ms (debounced search)
  4. Hapus text untuk reset search
Pro Tip: Kombinasikan filter Owner + Status + Search untuk hasil yang sangat spesifik!
Lihat Detail Project
  1. Pada card project yang ingin dilihat
  2. Klik button "Project Detail" (biru)
  3. Anda akan diarahkan ke halaman detail project
  4. Di halaman detail, Anda bisa lihat:
    • Informasi lengkap project
    • List nodes dalam project
    • Configuration settings
    • Activity logs
 Quick Actions pada Card

Setiap project card punya 3 quick action buttons:

1. Project Detail (Button Biru)
  • Buka halaman detail lengkap project
  • Edit project information
  • Manage project settings
2. View Nodes (Button Outline)
  • Direct link ke halaman Nodes
  • Filtered by project ini
  • Quick access untuk manage nodes
3. Telemetry (Button Secondary)
  • View real-time telemetry data
  • Monitor sensor readings
  • Analyze trends & patterns

Status Badge Meanings:
Status Deskripsi Operational State
Active Project operational dan berfungsi normal Fully Operational
Maintenance Project sedang dalam scheduled maintenance Maintenance Mode
Offline Project tidak aktif atau semua nodes offline Not Operational
Resource Metrics Explained:
12
NODES

Nodes = jumlah IoT devices yang terdaftar dalam project ini. Setiap node bisa punya multiple sensors.

48
SENSORS

Sensors = total sensor di semua nodes. Satu node bisa punya 1-N sensors tergantung konfigurasi.

5
ALERTS

Alerts = jumlah alert aktif yang perlu perhatian. Angka > 0 ditampilkan merah untuk highlight urgency.

Last Sync Time Format:
2 min ago → Sync dalam beberapa menit terakhir
1 hour ago → Sync beberapa jam lalu
Yesterday → Last sync kemarin
2 days ago → Lebih dari 1 hari (perlu attention)

Contoh Penggunaan

Scenario: Monitor Project Status

Situasi: Anda ingin cek project mana yang sedang maintenance

Langkah:

  1. Klik tab Maintenance
  2. Lihat semua project dengan status maintenance
  3. Check detail untuk tahu schedule maintenance
  4. Plan accordingly untuk minimize downtime

Result: Clear visibility project maintenance schedule

Scenario: Filter by Owner

Situasi: Owner "PT ABC" ingin lihat semua projectnya

Langkah:

  1. Klik dropdown "Owner"
  2. Pilih "PT ABC"
  3. Cards otomatis filtered untuk PT ABC only
  4. Review semua project milik owner tersebut

Result: Owner-specific project view untuk focused monitoring

Scenario: Cari Project dengan Alert

Situasi: Anda perlu cek project mana yang punya active alerts

Langkah:

  1. Scan cards untuk angka merah di "Alerts" metric
  2. Klik "Project Detail" pada card dengan alerts
  3. Review alert details & severity
  4. Take action sesuai alert priority

Result: Quick identification project yang perlu immediate attention

Scenario: Quick Access ke Telemetry

Situasi: Anda ingin monitor real-time data project tertentu

Langkah:

  1. Cari project yang ingin di-monitor
  2. Klik button "Telemetry" pada card
  3. View real-time sensor data
  4. Analyze trends & anomalies

Result: Direct access ke telemetry data tanpa multiple navigations

Scenario: Search Project by Location

Situasi: Anda ingin cari semua project di "Jakarta"

Langkah:

  1. Ketik Jakarta di search box
  2. Wait 400ms untuk debounced search
  3. Cards filtered untuk project di Jakarta
  4. Review lokasi spesifik di setiap card

Result: Location-based project filtering untuk regional monitoring

Tips & Best Practices

Quick Tips:
  • Gunakan Owner filter untuk segment by client/owner
  • Badge count di tabs = quick overview distribusi status
  • Alert count merah = prioritas tinggi, cek immediately
  • Last sync > 1 day = potential connectivity issue
  • Card view = easier scanning untuk large number of projects
  • Quick action buttons = direct navigation tanpa extra clicks
Perhatian:
  • Offline status = semua nodes tidak responding, perlu investigasi
  • Maintenance projects = data collection might be paused
  • High alert count (>5) = potential critical issue
  • Long last sync time = check node connectivity
  • Empty location = project setup incomplete
Pro Tips:
  • Kombinasi Owner + Status filter untuk targeted monitoring
  • Regular export untuk historical trend analysis
  • Gunakan "Group by Owner" untuk client reporting
  • Monitor maintenance projects untuk schedule optimization
  • Search by location untuk regional operations
  • Bookmark frequently monitored projects
