Getting Started: Login to System Learn how to access the IoT Monitoring System

beginner 5 minutes IoT Support Team

Access the Login Page

Open your web browser and navigate to the IoT Monitoring System URL provided by your administrator.

URL Format: https://iot.yourcompany.com
What You'll See:
  • IoT Monitoring System logo and branding
  • Login form with email and password fields
  • "Forgot Password?" link
  • System version information (footer)

Pro Tip:

Bookmark the login URL for quick access in the future.

Enter Your Credentials

Input your login information carefully. Both fields are required.

Email/Username Field
Enter your registered email address
Password Field
Case-sensitive password
Important: Passwords are case-sensitive. Ensure Caps Lock is OFF.

Login Options

Configure your login preferences before signing in.

Available Options:
Option Description
Remember Me Keeps you logged in on this device
Forgot Password Reset password via email
Need Help? Contact support team

Complete Login

Click the "Sign In" button to access the system.

What Happens Next:
  1. System validates your credentials
  2. If successful, you'll see a loading screen
  3. You'll be redirected to your dashboard
  4. First-time users: Profile setup wizard appears
Success! You'll be redirected to the dashboard within 2-3 seconds.

Forgot Password

If you forgot your password, follow these steps to reset it.

Password Reset Process:
1
Click "Forgot Password?"
Find the link below login form
2
Enter Your Email
Type registered email address
3
Check Your Email
Look for reset email (check spam)
4
Click Reset Link
Open email and click the link
5
Set New Password
Enter your new password twice and submit
Note: Reset links expire after 24 hours. If expired, request a new one.

Troubleshooting

Common login issues and their solutions.

Problem Solution
Invalid credentials
  • Check Caps Lock is OFF
  • Verify email spelling
  • Try password reset
Account locked Contact administrator - too many failed attempts
Page won't load
  • Check internet connection
  • Clear browser cache
  • Try different browser
Reset email not received Check spam folder, wait 5-10 minutes, or request new link
