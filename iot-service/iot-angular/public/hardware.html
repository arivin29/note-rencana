FAQ

Pertanyaan Umum

Jawaban untuk pertanyaan yang sering ditanyakan oleh calon pengguna.

Berapa lama proses instalasi?

Proses dari PO hingga sistem live membutuhkan waktu maksimal 30 hari. Ini mencakup pengadaan hardware, konfigurasi, pengiriman, dan instalasi di lokasi.

Bisa integrasi dengan sistem billing PDAM?

Bisa banget! Platform HELIOS mendukung transfer data via Webhook, MySQL, PostgreSQL, dan HTTP POST — memudahkan integrasi dengan sistem billing atau database existing PDAM.

Bagaimana jika sinyal 4G lemah?

Semua node DEVETEK mendukung dual-band 4G dan 2G. Jika sinyal 4G lemah, perangkat otomatis fallback ke jaringan 2G. Untuk area sangat terpencil, tersedia opsi LoRa (Type C) tanpa perlu SIM Card.

SIM Card pakai apa? Siapa yang bayar?

Kami merekomendasikan Telkomsel M2M atau Halo untuk stabilitas jaringan. Ada 2 opsi: (1) PDAM menyediakan SIM Card sendiri, atau (2) DEVETEK menyediakan dan mengelola SIM Card untuk Anda.

Kalau cloud down, data hilang tidak?

Tidak. DEVETEK-HELIOS menggunakan arsitektur database terdistribusi dengan ClickHouse DB, dilengkapi server backup. Setiap node juga memiliki SD Card buffer — data tetap tersimpan lokal dan otomatis sync saat online kembali.

Apakah ada opsi sewa hardware?

Saat ini tidak ada opsi sewa. Hardware dibeli satu kali (menjadi aset PDAM), sementara layanan cloud HELIOS berlangganan per node. Model ini memberikan kepemilikan penuh atas perangkat dan fleksibilitas dalam pengelolaan.
