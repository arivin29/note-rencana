# IoT Service — Project Guide (Angular frontend)

Multi-tenant IoT monitoring platform. This repo is the **Angular 20 frontend**. The backend is a separate **Goravel (Go)** repo.

## Repos
- Frontend (here): `iot-angular` — Angular 20, NgModule (`standalone: false`), Bootstrap 5 admin template, ng-openapi-gen SDK.
- Backend: `/Users/arivin29macmini/Documents/DEVETEK/iot-backend-go` — Goravel (Gin + GORM), PostgreSQL + ClickHouse + MQTT, JWT auth.

## Non-negotiables
- **API contract is shared & fixed** (camelCase JSON). List = `{ data, meta:{total,page,limit,totalPages} }`; single item returned directly; error = `{ statusCode, message, error }`. Do not invent new envelopes.
- **Do not hand-edit `src/sdk/core/`** — it's generated by ng-openapi-gen (`ng-openapi-gen.json`, input `http://localhost:3000/api-json`). Regenerate instead.
- All components are **NgModule, `standalone: false`**. Match existing module structure.
- Use the shared `<card>` / `<card-header>` / `<card-body>` components and Bootstrap utility classes; theme via `--bs-theme`.
- Multi-tenancy: `admin` sees all, `tenant` scoped to its `idOwner`. Respect role checks.

## Common commands
- Dev: `npm start` (ng serve). Build: `npm run build`. SDK regen: `npx ng-openapi-gen`.
