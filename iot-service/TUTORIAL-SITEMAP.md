## 🎨 Template Pattern (Bootstrap)

Semua tutorial menggunakan pattern yang sama dari `form-elements.html`:

### Structure:
```html
<div class="container">
  <div class="row justify-content-center">
    <div class="col-xl-10">
      <div class="row">
        <!-- Main Content (col-9) -->
        <div class="col-xl-9">
          <ul class="breadcrumb">...</ul>
          <h1 class="page-header">...</h1>
          <hr class="mb-4">
          
          <!-- Sections -->
          <div id="section1" class="mb-5">
            <h4>Section Title</h4>
            <card><card-body>...</card-body></card>
          </div>
        </div>
        
        <!-- Sidebar Navigation (col-3) -->
        <div class="col-xl-3">
          <nav-scroll>
            <a class="nav-link" href="#section1">...</a>
          </nav-scroll>
        </div>
      </div>
    </div>
  </div>
</div>
```

### Benefits:
- ✅ No custom CSS needed
- ✅ Auto scroll spy
- ✅ Consistent design
- ✅ Responsive layout
- ✅ Dark theme ready
